# Карта NEXUS404 для разработки

## Границы проекта

Хаб — Node.js 24, обычные HTML/CSS/JS, без frontend-фреймворка. Геката — Java/Android SDK, без AndroidX/Kotlin. В APK остаются только банковские операции и Band 11, включая уведомления и управление системным плеером. Пользователь ожидает полный исходный ZIP и подписанный APK, устанавливаемый поверх прежнего.

Не путать: Каллиопа — статьи/заметки, Клио — книги, Дионис — Shikimori, Гипнос — фильмы. Полная таблица модулей в README. Геката не является модулем сервера; Мнемосина — серверные инструменты копирования.

## Инварианты, которые нельзя потерять

- Не возвращать Steam QR-login и не имитировать мобильный клиент Steam. Ошибка достижения отдельной игры не должна стирать библиотеку или ключ.
- BLE/GATT — необходимый транспорт Band 11. Системная пара Android не заменяет протокольную авторизацию Huawei. Секреты не сбрасываются при сетевой ошибке.
- Один сериализованный GATT-обмен, поколение соединения отсекает старые callback. Не считать запись Android подтверждением ответа браслета. Не обходить GCM, CRC и SHA-256.
- Ошибка необязательного формата отделяется от ошибки криптографии. Не выдавать частичный проход за полную синхронизацию. Не угадывать неизвестные стадии сна/поля устройства.
- Подтверждать файл браслету только после долговечного сохранения записей. Удалять исходящую очередь только после явного ответа хаба. Адрес/ключ приёмника связан с очередью. Перенос на другой хаб при непустой очереди запрещён. По запросу пользователя в 0.1.41 разрешена замена ключа на том же хабе: явное подтверждение в приложении, успешная проверка нового ключа, остановленное чтение и отсутствие активной отправки. Прежние привязки сохраняются в зашифрованной конфигурации; пакеты не переписываются и не удаляются до подтверждения приёмником.
- Снимок шагов не суммировать с интервальной историей. Перекрывающиеся измерения дедуплицировать с учётом источника и времени. Не отправлять сырые неизвестные поля в ИИ-сводку.
- Деньги: идентификатор события обеспечивает идемпотентность. Коды входа/баланс не пересылаются. Не считать незнакомый ответ сервера успешной доставкой.
- Плеер хаба живёт в оболочке, а не в iframe модуля. Переключение страницы не должно уничтожать audio. Play с часов — системному Android-плееру; APK не содержит отдельного Аполлона.
- Все private-маршруты требуют сессию; bearer имеет только область своего источника. После асинхронного чтения тела повторять проверку разрешения перед записью. Не включать токены в обычные логи и URL уведомлений.
- Сохранять прозрачность и общий компактный стиль. Использовать `Nexus.confirm/prompt` вместо браузерных окон.
- Не стирать пользовательские файлы ради очистки. Legacy API загрузки/музыки/уведомлений пока сохранены для старых клиентов; интерфейс позволяет отозвать старые ключи, но не предлагает удалённые функции APK.

## Проверки

```sh
npm --prefix 02-hub ci --omit=optional
npm --prefix 02-hub test
ANDROID_TEST_JAR=/path/to/android-all.jar node android/test.mjs
```

JVM runner каждый раз компилирует все Java-файлы в новый временный каталог; при ошибке компиляции запуск тестов запрещён. `ECJ_JAR` позволяет использовать ECJ вместо javac. SDK `android.jar` содержит заглушки и не подходит для выполнения JVM-тестов. Сборка: `node android/build.mjs`, переменные — в android/README.md.

Протокольные фикстуры не заменяют реальный Band 11. Не объявлять подтверждёнными батарею, ночной сон, длительную стабильность радио или успешный деплой на VPS без измерений пользователя. Проверенные и непроверенные возможности указаны в android/HUAWEI.md.

## Выпуск

Версия хаба: `02-hub/package.json`, корень lockfile и манифесты модулей. Версия APK: `android/AndroidManifest.xml`, код увеличивается; интерфейс Android читает установленную версию из manifest. Обновлять актуальные инструкции и CHANGELOG.

APK собирается в `02-hub/modules/balance/companion.apk`; этот файл должен побайтно совпадать с отдельным APK. Использовать прежний сертификат; не создавать другой ключ для удобства. Ключ и пароль не входят в Git/ZIP.

Архив — полный проект без внешней папки, `.git`, `node_modules`, серверных баз/секретов и временных сборок. Включать `02-hub/Dockerfile.dockerignore`, исходники Android и тесты. Публикация в GitHub и установка на VPS — отдельные действия; локальная сборка их не выполняет. Не возвращать удалённый пользователем `.github`.

Текущий статус: хаб 0.35.78, APK 0.1.44/code45 собран и подписан прежним сертификатом; 15 JVM-наборов пройдены. companion.json создан сборщиком из нового APK. Реальную доставку очереди и радио проверяет пользователь на телефоне.
