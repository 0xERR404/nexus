# Проверка NEXUS404 0.35.268

Проверено 16 октября 2026 года. Основа — 0.35.267.

Изменён порядок отображения журнала обновления: последние 40 записей выводятся от новых к старым. Разворачивается копия массива на клиенте; серверная история, расчёт длительности, выполнение обновления и защита резервных копий не меняются.

Проверены существующие проверки индикатора обновления, синтаксис JavaScript, JSON, версии модулей и полнота выпуска. ZIP сверяется с исходниками и проверяется по CRC. Сервер пользователя не изменялся. Ранее проведённые проверки механизма обновления описаны в истории выпуска 0.35.267; Docker и systemd на VPS в этой проверке не запускались.

Для изменения порядка журнала достаточно веб-обновления. Для включения проверки отдельного контейнера по-прежнему требуется серверная служба из полного выпуска 0.35.267 или новее, применённого через установщик.
