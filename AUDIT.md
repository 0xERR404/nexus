# Проверка NEXUS404 0.35.257

Проверено 16 октября 2026 года. Основа — 0.35.256. Изменения подготовлены в исходниках; рабочий VPS не обновлялся и хаб на нём не удалялся.

## Что добавлено

- Удаление приложения через установщик с сохранением файлов, баз, входа и настроек модулей; отдельное восстановление из полного выпуска. Код модулей заменяется, пользовательский каталог data не удаляется. Общие службы сервера и удалённые VPN-ноды не удаляются.
- Раздел «Настройки → Обновление хаба». Выбор только из одного проекта с точным именем NEXUS404; публичную установочную ссылку Дедала включать не требуется.
- Проверка принадлежности выпуска, формата и возраста запроса, версии, SHA-256, безопасных путей ZIP, CRC, состава и согласованности версий архива. Дубликаты имени, повторные запросы и установка старых версий блокируются.
- Отдельная служба сервера: фиксированный запрос, закрытое рабочее хранилище, общий замок установщика, состояние операции и восстановление прерванной установки. Docker socket не передаётся контейнеру. Установщик и Compose загруженного архива не выполняются.
- Сборка до остановки приложения, согласованная резервная копия после остановки, проверка свободного места для копии и возврата, проверка хаба и включённых модулей. При ошибке запуска возвращаются образ, код и данные; неудачное состояние тоже сохраняется. Есть ручной возврат из копии в меню.
- Общая проверка ZIP для Дедала и службы обновления. Не добавлены зависимости npm.

## Проверки

Общий последовательный прогон: **333 теста, 333 успешно, 0 ошибок, 0 пропусков**. В параллельном прогоне Windows один существующий стресс-тест VPN встретил EPERM при замене открытого файла; полный повтор последовательно прошёл. После завершающих правок проверки обновления, HTTP и меню пройдены повторно.

Новые сценарии проверяют точную фильтрацию проектов, дубликаты, отсутствие утечки токенов, подтверждение установки, недоступную службу, повторные запросы, устаревшие/повреждённые запросы, неправильные версии и SHA-256, ZIP traversal/CRC, отмену удаления и отказ трогать неизвестные каталоги. Файлы и вход сравниваются побайтно после удаления/восстановления. Проверены успешная замена кода, ошибка сборки до остановки хаба и возврат прежних кода/данных после неудачного запуска.

HTTP-проверки подтверждают авторизацию, защиту от постороннего Origin, отсутствие кэширования состояния, доступность страницы и ресурсов. В браузере проверены настольный вид, ширина 390 px, выбор версии, обязательное подтверждение, блокировка повторной отправки и отображение принятого запроса. На телефоне нет горизонтального переполнения. Использовался локальный тестовый стенд без настоящей установки на VPS.

В поставке 259 файлов. Синтаксически проверены 172 JavaScript-файла и прочитаны 24 JSON. Проверен явный список файлов установщика. ZIP собирается только из каталога проекта; рабочие базы, тестовые файлы, журналы, зависимости, ключи и сертификаты не включаются.

## Границы проверки

Команды Docker, cp и systemd в сценариях транзакции заменялись управляемыми тестовыми исполнителями. Реальные Linux-права, сборка контейнера и обновление/откат на рабочем VPS в этой среде не проверены. Нельзя считать это доказательством отсутствия любых сбоев диска, Docker или миграций будущих выпусков.

Веб-обновление предназначено для совместимых выпусков с hubUpdateSchema: 1. ОС, установщик, хостовые службы и VPN-ноды обновляются через меню полного проекта. Перед первым использованием нужно один раз установить этот выпуск штатным установщиком. Смена структуры данных требует миграций в выпуске; произвольный старый архив не является безопасным откатом базы.

Резервные копии обновлений и неудачные состояния сохраняются на том же сервере и автоматически не очищаются. Требуется контроль свободного места и отдельная внешняя копия для защиты от потери диска/VPS. При невозможности автовозврата служба блокирует дальнейшие веб-обновления и оставляет копию для восстановления.

Зависимости по сравнению с 0.35.256 не менялись; новый сетевой npm-аудит в этом выпуске не запускался. Ранее отмеченное предупреждение о транзитивном ip 2.0.1 не объявляется устранённым. Ограничения фонового аудио PWA со стороны мобильной ОС также сохраняются.
