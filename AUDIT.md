# Проверка NEXUS404 0.35.262

Проверено 16 октября 2026 года. Основа — 0.35.261. Исправлена конфигурация серверной службы обновления, вызвавшая на VPS пользователя ошибку mkdir /root/.docker: read-only file system.

Установщик создаёт /var/lib/nexus404-updates/private/docker с владельцем root и правами 0700, задаёт DOCKER_CONFIG в окружении systemd-службы. ProtectHome=true, PrivateTmp=true и NoNewPrivileges=true сохраняются. Для читаемого журнала сборки задан BUILDKIT_PROGRESS=plain. Каталог конфигурации Docker не передаётся контейнеру хаба.

27 тестов прошли без ошибок: проверена созданная конфигурация службы, существование и возможность записи в отдельный каталог, сохранение защитных параметров, сценарии резервного копирования и отката, журнал, HTTP всех 17 модулей и PWA-ресурсы. На Windows реальная изоляция systemd и права Linux не воспроизводились; проверка режима 0700 выполняется тестом только на Linux. Попытка обнаружить локальную WSL-среду завершилась отказом доступа, ограничения не обходились. Реальный Docker build и применение исправления на VPS здесь не выполнялись.

Статическая проверка: 259 файлов, 172 JavaScript-файла, 24 JSON. Архив проверяется по CRC и побайтному соответствию исходникам. Тестовые файлы и зависимости не входят в выпуск.

Для действующей службы можно отдельно применить drop-in с DOCKER_CONFIG и выполнить systemctl daemon-reload. После этого нужно повторно отправить запрос обновления: неудачная операция автоматически не воспроизводится. Полный установщик выпуска также записывает исправленную службу. Для включения усиленных проверок и журнала из 0.35.261 требуется обновить серверную службу через установщик, если она ещё старая.
