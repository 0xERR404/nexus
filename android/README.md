# Геката · NEXUS404 · 0.1.38

Android 8+; Band 11 проверяется пользователем на Android 13. В APK только деньги и браслет. Собственный код — Java, без AndroidX, Kotlin и сторонних runtime-библиотек.

## Деньги

В настройках Плутоса создай источник, в Гекате укажи адрес HTTPS, ключ и банк. Выбери один канал: пуши или новые SMS от явно разрешённых отправителей. Для Сбера — стиль «Стандарт». Старые SMS приложение не читает. Коды входа не передаются.

Покупки с распознанным магазином отправляются автоматически. Доходы и возвраты — только проверенные форматы; автоматическое проведение включается отдельно в настройках источника хаба. Неизвестные операции не угадываются. Очередь сохраняется без сети, отправка повторяется автоматически.

## Браслет

В настройках Асклепия хаба создай ключ и сохрани его в Гекате → Band 11 → Настройки подключения. При первом подключении выбери браслет и подтверди запросы сопряжения. Затем кнопка «Подключить» использует сохранённое устройство без сканирования. «Выбрать другой браслет» находится в настройках.

Системная пара Android, канал Bluetooth LE/GATT и авторизация Huawei нужны вместе. GATT — транспорт Bluetooth, не отдельное приложение. Huawei Health, Health Connect и аккаунт Huawei не нужны. Ключи не удаляются при временном обрыве.

Автоматика: счётчик и заряд примерно каждые 5 минут; базовая история каждые 15 минут; подробный сон, стресс и сводки тренировок раз в час. «Прочитать сейчас» запускает полный проход. Android может задерживать фоновые задания. Уведомления и команды музыки идут по событиям, без ожидания этих интервалов, но сериализуются с текущим обменом.

Для уведомлений выбери приложения и разреши доступ Android. Для управления музыкой включи плеер телефона. Выбирается играющая сессия, затем последний использованный плеер. Если сессии больше нет, команда Play передаётся Android как медиакнопка. Запуск после принудительной остановки приложения или уничтожения браузера не гарантируется и зависит от поддержки возобновления самим плеером.

[Данные и ограничения Band 11](HUAWEI.md).

## Обновление

Устанавливай поверх прежней Гекаты. Ключи денег/браслета, системная пара и неотправленные измерения сохраняются. Удалены старые APK-модули Health Connect, папки, отдельный Аполлон и Гермес, их задания, настройки и временные кэши. Файлы пользователя и модули хаба не удаляются. Старые неиспользуемые ключи этих модулей на сервере можно отозвать отдельно.

## Сборка

Нужны JDK 17+, Node.js, Android SDK `platforms;android-36`, `build-tools;35.0.0`. Сборка не скачивает библиотеки. Можно указать `ECJ_JAR` вместо javac.

```sh
export ANDROID_HOME=/path/to/android-sdk
export NEXUS_ANDROID_KEYSTORE=/private/hecate.p12
export NEXUS_ANDROID_PASSWORD_FILE=/private/password.txt
node android/build.mjs
```

APK: `02-hub/modules/balance/companion.apk`; другой путь — `NEXUS_ANDROID_OUTPUT`. Alias ключа — `hecate`. Сертификат должен совпадать с установленной версией. Ключ и пароль не включаются в архив.

## Проверка на телефоне

Проверить после обновления: подключение без поиска; 30 минут с выключенным экраном; выключение/включение Bluetooth; выход браслета из зоны связи; восстановление сети и доставку очереди. Для музыки: пауза/Play/следующий с часов и гарнитуры, смена приложения-плеера, завершение очереди. Для сна нужна реальная ночь и сравнение длительности/стадий с браслетом. Замер расхода батареи — одинаковое время и условия до/после; локальные тесты не заменяют этот замер.

Начиная с 0.1.37 доступны минутные калории/расстояние, 20 распознаваемых показателей сна и чтение страниц тренировок 17/0A при подтверждённой поддержке. Эти данные требуют хаб 0.35.74 или новее. Возможности приёмника обновляются автоматически при отправке; после обнаружения нового приёмника следующий опрос повторяет базовую историю за 7 суток. Подробный сон и расширенные данные можно запросить кнопкой «Прочитать сейчас». В Асклепии есть экспорт JSON за выбранный день, включая исходные дополнительные поля.

## Автоматические тесты

Укажи полный Android framework JAR для выполнения JVM-тестов, например `org.robolectric:android-all:13-robolectric-9030017` (только среда тестирования, в APK не включается). SDK `android.jar` содержит заглушки и здесь не подходит.

```sh
ANDROID_TEST_JAR=/path/to/android-all.jar node android/test.mjs
```

При необходимости добавь `ECJ_JAR=/path/to/ecj.jar`. Скрипт компилирует все исходники и запускает все `*Test.java` в новом временном каталоге; старые class-файлы использоваться не могут. Проверяются форматы банка, криптография/сопряжение, пакеты Bluetooth, история, файлы, сон, тренировки, уведомления и подтверждения HTTPS. Это JVM-проверки, не эмуляция Android lifecycle или реального радио.
