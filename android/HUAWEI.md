# Band 11 · прямой Bluetooth

Геката 0.1.44 / NEXUS404 0.35.78. Android создаёт системную пару; приложение поддерживает Bluetooth LE/GATT и защищённый Huawei-сеанс HiChain3. Транспорт нельзя заменить одним флагом «сопряжено». Сопряжение и успешное чтение базовой истории подтверждены журналами пользователя; все возможности устройства этим не подтверждаются.

| Данные | Реализация и ограничение |
|---|---|
| Заряд, счётчик шагов | Снимок; не прибавляется к интервальным шагам |
| Минутные шаги, пульс, SpO₂, калории, расстояние | Базовая история 07; передаются только присутствующие поля |
| Базовый сон | Известные стадии сопоставлены, неизвестные остаются неизвестными |
| TruSleep | Словарь 700013, sequence_data; светлый/глубокий/REM/бодрствование/дневной сон; требуется проверка реальной ночи |
| Стресс | rrisqi_data.bin, формат v3, допустимые оценки 1–100 |
| Тренировки | Сводки 17/07–08: время, доступные калории, расстояние, шаги, длительность и тип |
| Показатели сна | Оценка, эффективность, пробуждения/повороты, ночной пульс/SpO₂/дыхание, HRV и базовый диапазон; только присутствующие поля |
| Страницы тренировок | 17/0A: пульс, скорость, каденс, высота и другие отсчёты; неизвестное расширение сохраняется без интерпретации |
| GPS, температура, ЭКГ | В этой реализации не читаются. У обычного Band 11 датчики температуры и ЭКГ не заявлены Huawei |

Числовые поля словаря сна сохраняются также под исходными ID. Поля сводок тренировок и полезная нагрузка RRI сохраняются в JSON-экспорте, неизвестные значения не объявляются физиологическими метриками. Добавлен sleep_state.bin через 0A/2C: интервалы сна без детализации стадий и без подтверждения завершённости. Сырые ACC/PPG из sleep_data.bin пока не запрашиваются: алгоритм их интерпретации не реализован. Отсутствующее измерение не превращается в ноль. Полный экспорт всех данных браслета пока не достигнут.

Текущее значение читается раз в 5 минут, базовая история раз в 15 минут, расширенная раз в час. Первое чтение — до 7 суток, последующие с перекрытием 30 минут; сон — минимум двое суток. Ручное чтение повторно запрашивает базовые 7 суток и запускает расширенный проход. При неизвестном формате необязательной истории связь не разрывается, частичный проход не объявляется полностью завершённым. Ошибки криптографической проверки не игнорируются.

Страницы записываются в зашифрованную очередь до подтверждения завершения передачи файла. Отправка HTTPS автоматически повторяется, удаление пакета — только после ответа хаба о приёме всех записей. Стабильные ID обеспечивают обновление вместо дублирования. Очередь ограничена 16 МиБ/2048 пакетами: переполнение показывается как ошибка, старые записи не стираются.

Подробный сон считается завершённым эвристически: известные стадии, полное покрытие и окончание не менее двух часов назад. Это не явный флаг завершения от браслета. Перед автоматическими платными отчётами нужно проверить результат на реальной ночи.

При разрывах задержки повторов: 10 с, 30 с, 1, 2, 5, затем 15 минут. Bluetooth выключен — ожидание системного события включения. Ошибки ключа/привязки требуют внимания пользователя; бесконечное перепривязывание и сброс браслета запрещены. WakeLock удерживается только во время обмена, с ограничением времени.

Музыка управляет системными MediaSession телефона. При отсутствии сессии используется AudioManager.dispatchMediaKeyEvent(PLAY), без произвольного запуска экранов приложений. Android решает, может ли последний плеер возобновиться. Удалённая вкладка PWA не поддерживает собственную живую медиасессию.

Протокольная сверка: Gadgetbridge, Codeberg, ревизия bd835fd550ec27d1c6cce0dbd770319437c3b01a. Gadgetbridge не входит в APK и не нужен на телефоне. Криптография, границы пакетов, фрагментация, файлы, стадии и курсоры проверяются тестами; длительная радио-стабильность и расход батареи требуют реального Band 11.

Экспорт дня: Асклепий → «Скачать измерения», авторизация обязательна. Технические расширения не включаются в числовую сводку DeepSeek. Страницы тренировок проверяются по номеру тренировки, страницы, длине, битовой маске и времени; каждый очередной пакет сохраняется перед дальнейшим запросом. Общий проход ограничен двумя минутами; при превышении завершение не подтверждается. GPS-маршруты и неизвестные форматы пока не реализованы.

Спецификация датчиков Band 11: https://consumer.huawei.com/en/wearables/band11/specs/ . Перечислены IMU, оптический датчик пульса и освещённость; ЭКГ и температура не заявлены. Новые поля и команды протестированы на синтетических пакетах, не на физическом устройстве.


## Запросы 0.1.42

Ответ 01/03 для 2C сохраняется в диагностике, но больше не блокирует 01/31: общий список команд не определяет способ файловой синхронизации. 01/31, тег 02: бит 1 выбирает 2C для обычного сна, бит 2 — 2C для RRI; без бита используется 0A. Словарь сна из 01/37 выбирает sequence_data / 700013 через 2C независимо от бита обычного сна. Без словаря запрашивается sleep_state.bin. Файл стресса запрашивается отдельно, включая продолжение после отказа и ошибки необязательного формата сна. Ошибки криптографии и тайм-аут соединения прекращают сеанс.

Для 0A: 01 — список файлов с окном времени; 02 — параметры нужного типа (сон 1, RRI 4); 03 — размер; 04/05 — ограниченные блоки с последовательными номерами; 06 — подтверждение только после сохранения разобранных записей. Протокол 0A не предоставляет SHA-256: принимаются только GCM-защищённые блоки с проверкой CRC транспортом, порядка и размера. Для 2C проверка SHA-256 сохранена. Незашифрованные блоки 0A не поддержаны.

Исходный тип 07/0D сохраняется в sleep.deviceFields.04 и гистограмме журнала; неизвестный код не превращается в известную стадию. Хаб 0.35.78 сохраняет эти поля в экспорте. Синтетические проверки подтверждают запросы, маршруты 0A/2C и проверки пакетов; фактические ночные 6:46 и стресс Band 11 ещё не подтверждены.

В 0.1.43: неизвестный/отсутствующий флаг 05 в 2C/03 оставляет защищённый режим GCM; только явный 01 разрешает открытый запрос блоков. Хеш 2C проверяется в обоих случаях. При ошибке формата открытого файла посылается 2C/06 со статусом 2 перед запросом следующего файла. Код отказа 144001 сохранён без неподтверждённой расшифровки.


## Настройки измерений 0.1.44

По явному нажатию «Применить к браслету» проверяется поддержка 07/17 (автоматический пульс), 07/1C (реальное время), 07/24 (автоматический SpO₂). Запись: тег 01, однобайтовое 0/1, шифрование GCM. Режим реального времени использует 1C вместо 17; при переходе в обычный автоматический режим сначала выключается 1C, затем включается 17. Выключение пульса выключает обе поддержанные команды. Никакие пороги тревог не изменяются.

Успех отображается лишь после явного кода результата 7F=100000. Отсутствие такого кода не считается подтверждением. Отказ/тайм-аут одной команды не объявляет другой показатель недоступным; криптографические ошибки по-прежнему прерывают сеанс. Источник формата: FitnessData.EnableAutomaticHeartrate, EnableRealtimeHeartRate, EnableAutomaticSpo и SetAutomaticHeartrateRequest той же зафиксированной ревизии протокола. Эти исходники служат справочником; внешнее приложение и библиотека не добавлены в APK. Синтетические тесты пройдены, реальная запись настроек на устройстве пока не подтверждена.
