## 0.35.78 · Геката 0.1.42 / code 43

2 октября 2026 года. Исправлен преждевременный отказ файлового обмена: маска общего запроса 01/03 больше не блокирует выбор протокола по 01/31. Диагностика показывает полученные флаги и выбранный маршрут. Сон: словарь sequence_data через 2C либо интервалы sleep_state.bin через 0A/2C. Стресс: rrisqi_data.bin через 0A/2C по отдельному биту поддержки. Реализованы запрос списка, параметры, размер, получение блоков и подтверждение 0A после долговечного сохранения. Проверяются CRC, GCM, порядок, границы и длина; существующий SHA-256 в 2C сохранён. Отказ/неизвестный формат одного файла не отменяет запрос следующего; криптографическая ошибка и тайм-аут прекращают сеанс.

Ручное чтение повторяет базовое окно 7 суток. Неизвестные типы 07/0D сохраняются для диагностики и в экспорте хаба; стадии не угадываются. Sleep state даёт только интервал без детализации и не считается завершённой ночью. Исправлена категоричная подпись о неподдержке браслетом. Полный сбор всех форматов, сырые sleep_data.bin, реальные 6:46 и стресс физического Band 11 пока не подтверждены.


Проверки: 14 JVM-наборов и 24 теста Асклепия прошли. Общий прогон: 465 из 466, прежняя ошибка видеотеста — отсутствует node_datachannel.node в среде. Версия APK/code и прежний сертификат проверены, подпись v2/v3 действительна.

## 0.35.75 · Геката 0.1.38 / code 39

Аудит подготовлен 1 октября 2026 года. Предыдущая поставка: 0.35.74 / 0.1.37.

### Исправлено

- Банковская отправка: отмена относится к конкретному Android-заданию, а не ко всей службе. Незнакомый `state` в HTTP 200 больше не удаляет операцию из очереди. Остановленный запрос разрывает соединение; повторная доставка остаётся идемпотентной.
- Очередь браслета: восстановление AtomicFile учитывает оставшийся резервный файл даже при отсутствии основного; его размер входит в лимит. Проверка возможностей хаба корректно обрабатывает перевод часов назад.
- Bluetooth: продолжение файлового обмена после сохранения очереди использует тот же выбор шифрования и ожидаемую команду, что и обычная отправка. Неверный необязательный ответ уведомлений не разрывает соединение. Ошибка одной страницы тренировки позволяет перейти к следующей тренировке. После отказа метаданные плеера не считаются успешно отправленными.
- Плеер Android: наблюдение за активными медиасессиями позволяет замечать смену приложения; играющая сессия приоритетнее буферизующейся. Сохранён запуск последнего доступного плеера через системную медиакнопку.
- Асклепий: перекрывающиеся страницы с одним отсчётом пульса не увеличивают его вес в среднем; новая корректировка имеет приоритет. Пустые показатели сна не скрывают реальные показатели другого источника. Некорректная дата экспорта возвращает ошибку запроса.
- Доступ: Ника, Дионис, Оракул, Аполлон и Гермес повторно проверяют сессию после чтения JSON. Журнал активности также проверяет отзыв сессии. Загрузка музыки/обложки проверяет разрешение до сохранения результата и очищает временные файлы при отказе.
- Настройки хаба: убраны предложения подключить удалённые из APK папки, отдельный плеер и Гермес. Ранее выданные ключи можно отозвать; совместимые серверные API и пользовательские данные сохранены.
- Установщик проверяет полный список необходимых файлов исполнения, включая новые общие скрипты. Docker ignore остаётся необязательным для проверки установки, но включён в полный ZIP.

- Один интерфейс отзыва старых APK-ключей вместо двух отдельных скриптов и копии логики в Гестии.
- Сборка APK очищена от пустых списков прежних внешних зависимостей. Добавлен единый `android/test.mjs`: новая компиляция перед каждым запуском, без старых class-файлов.

- Общий README сокращён с исторической простыни до актуальной инструкции. Обновлены Android README и контракт измерений; добавлена карта `AGENTS.md`. История этого аудита находится здесь, прежние поставки остаются отдельными архивами.

### Проверить 2 октября на телефоне

1. Установить APK поверх прежнего, без удаления данных. Проверить сохранение банковского подключения, ключа браслета и очереди.
2. Оставить телефон заблокированным на 30–60 минут; сравнить время чтения и подтверждение приёма на сервере. Проверить обрыв/возврат Bluetooth и временное отсутствие сети.
3. С часов: Play, пауза, следующий, предыдущий; затем сменить приложение-плеер. В PWA переключить модули и проверить управление с гарнитуры. Отдельно проверить Play после обычного закрытия интерфейса; принудительно остановленный Android-плеер может не возобновляться.
4. Уведомление выбранного приложения и реальная банковская операция: сумма, магазин, одна запись при повторной доставке.
5. После ночи сравнить сон, стадии и показатели с браслетом; выгрузить JSON. Проверить реальную тренировку. Неизвестные форматы пока не объявляются поддержанными.
6. Расход батареи сравнивать за одинаковый промежуток и условия. Здесь не было физического телефона, поэтому суточная стабильность, энергопотребление и полный набор данных Band 11 не подтверждены.

Полное восстановление реального хаба на отдельном VPS также не выполнялось в этом аудите. Обновление API/добавление неподтверждённых форматов браслета в этот выпуск не включалось.
